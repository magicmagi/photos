## Features

- **Browse by category**: every category has its own shareable link
- **Sort by date**: newest or oldest first, optionally grouped by year
- **Share a single photo**: each photo has its own link (`#/photo/<id>`), with a copy button in the viewer
- **Photo viewer**: ← → to move between photos and Esc to close; swipe on phones
- **Chinese and English**: the site follows the visitor's browser language (Chinese for Chinese, English for everything else) and has a switch button
- **Works on phones and desktops**, and follows the system's light or dark mode

## Copyright & Privacy

- Public images are at most 1600 px on the long side, carry a "© Maggie T" watermark, and have all EXIF data removed, including GPS location
- **Originals and shooting details** (camera, lens, aperture, shutter, ISO) are encrypted with AES-256-GCM and can only be viewed with a password. Decryption happens in the browser; the password is never sent anywhere
- The source photo files are not in this repository

## How it works

A plain static site with no framework or build tooling, hosted on GitHub Pages.

```
index.html      page structure
style.css       styles
app.js          gallery, viewer, routing, unlock logic, languages
config.js       site settings: name, intro, social links, categories
photos.js       photo list (generated by build.py)
img/            public display images and thumbnails (watermarked)
secure/         encrypted originals and shooting details
build.py        import script
```

### Updating photos

1. Put photos into the local photo folder by category. Subfolder names match the category `key` in `config.js`
2. Run the import script and enter the password for viewing originals:
   ```bash
   pip install pillow cryptography
   python3 build.py
   ```
   It reads the EXIF capture date, creates watermarked display images and thumbnails, encrypts the originals, and updates `photos.js`
3. Commit and push. GitHub Pages updates within a minute or two

Titles, locations and descriptions go in `captions.json` in the photo folder; the script adds empty entries for new photos. Add `title_en`, `location_en` or `desc_en` to show different text to English readers.
